## Handoff checklist for the morning research pass

For each slot the research-agent must:

1. Find one Arabic-relevant story that fits the slot's bucket (see token
   ATLAS in `data/_template/media_hunter.py` and `ENGINE.md §2`).
2. Create `data/posts/2026-04-19-<kebab-slug>/` (pick a ≤3-word slug from the
   story — no TBDs, no `slot-N`).
3. Copy `data/_template/props.template.json` into the new directory as
   `props.json`, then fill ALL `{{PLACEHOLDER}}` tokens.
4. Set `"topicBucket": "<bucket-from-table-above>"` — must match the slot's
   assigned bucket exactly, else the slate is broken.
5. **Remove per-beat `accent` fields** so the bucket palette applies (the
   per-beat accents in the template are legacy from before bucket rotation
   landed). If the slug genuinely wants a custom mid-reel color, keep it —
   else strip.
6. Write `caption.txt` with IG hook + 5-7 hashtags per `reference_captions_format.md`.
7. Run `bash data/_template/hunt-media.sh <slug>` to fetch hero + 3 broll.
   - Brightness gate auto-rejects dark heroes (L<62).
   - If the source says 403 (Pexels key expired), rely on Wikimedia +
     motion-graphic fallback — no manual intervention needed.
8. Run `bash data/_template/render-reel.sh <slug> v3`. Pre-flight GUARDs 1–4
   WILL fail-fast on any remaining `{{…}}` placeholder or RTL-risky English
   subhead.
