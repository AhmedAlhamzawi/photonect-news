### The first render attempt failed 5/5 — root cause and fix

Run [30906346579](https://github.com/AhmedAlhamzawi/photonect-news/actions/runs/30906346579) failed
every slug in 2–17 seconds. Props validated fine; the failure was the Remotion **bundle**:

```
Error: Module not found: Can't resolve './compositions/TVCFlagship/TVCFlagship'
```

`my-video/src/Root.tsx` has imported `TVCFlagship` since commit **48c6368** (the vox engine, 02 Aug
23:48), but `my-video/src/compositions/TVCFlagship/` was **never added to git**. Locally the import
resolves and everything looks healthy; in CI the checkout gets a `Root.tsx` pointing at a module that
does not exist, webpack cannot build, and *every* slug dies before a single frame — including V10
slugs, and the V11→V10 fallback cannot save it because the bundle itself never builds.

The 2026-08-02 slate rendered at 23:38, **ten minutes before** that commit landed, so today was the
first render to hit it. Fixed in **54684d3** by committing the canonical `TVCFlagship.tsx` (not the
` 2/3/4.tsx` filesystem duplicates). It pulls in nothing local — react, remotion,
`@remotion/transitions`, `@remotion/google-fonts`, zod, all already in `package.json` — and exports
the three symbols `Root.tsx` imports.

**Audited all 32 relative imports in `Root.tsx`: TVCFlagship was the only untracked one.** That check
is now worth running before every slate — see warning 7.

7. **Add a pre-flight guard for untracked `Root.tsx` imports.** Today's first render lost ~7 minutes
   to a break that had been latent for two days and is invisible locally. The existing checklist item
   ("untracked Root.tsx comps silently break CI") only prompted me to check that `Root.tsx` *itself*

   component**. One-liner that catches it, worth putting in `generate-daily.sh` Phase 1:

   ```bash
   git show HEAD:my-video/src/Root.tsx | grep -oE 'from "\./[^"]+"' | sed 's/from "//;s/"//' |
   while read -r i; do b="my-video/src/${i#./}"; ok=""
     for e in .tsx .ts .jsx .js /index.tsx /index.ts .css; do
       git ls-files --error-unmatch "$b$e" >/dev/null 2>&1 && ok=1 && break; done
     [ -z "$ok" ] && echo "UNTRACKED IMPORT: $i"; done
   ```

8. **Filesystem duplicates are accumulating in the source tree.** `TVCFlagship 2.tsx`, ` 3.tsx`,
