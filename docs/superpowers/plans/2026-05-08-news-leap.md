## Task 2: Build the watcher script

**Files:**
- Create: `automation/scripts/watch-video.sh`
- Create: `automation/scripts/_watch_video.py` (helper)

- [ ] **Step 1: Write a download + frame-extract helper**

`automation/scripts/watch-video.sh <youtube_url> <out_dir>`:
1. yt-dlp the video at lowest practical bitrate (cap 720p, 30 MB max) into `<out_dir>/video.mp4`
2. ffmpeg extract 6 keyframes: `0s, 2s, 5s, 12s, 30s, end-3s` → `<out_dir>/frame_<n>.jpg`
3. yt-dlp also fetch transcript/subtitles if available → `<out_dir>/transcript.txt`
4. Print a small JSON manifest to stdout

- [ ] **Step 2: Test on one URL** (e.g., a Vox Borders 5-min video) — confirm 6 frames + transcript + manifest land in the out dir.

- [ ] **Step 3: Commit script**.

## Task 3: Dispatch 8 parallel watcher agents

**Files:**
- Create: `data/research/2026-05-08-watch-dossiers/<source-cluster>.md` (one per agent)

- [ ] **Step 1: Compose the watcher agent prompt template**

Each agent gets:
- Its source cluster (e.g., "Vox Borders")
- The 10-15 URLs assigned from the watch list
- Instruction to run `automation/scripts/watch-video.sh` on each URL into a per-video dir under `/tmp/watch/<cluster>/<slug>/`
- After downloading + extracting frames, the agent uses the Read tool to "see" each frame and the transcript to read what was said
- Per video, agent extracts:
  - 0-2s hook description (visual + audio + first word)
  - Mid-video hook (timing + technique)
  - Cut cadence (cuts/minute, on/off-beat, jump-cut?)
  - Visual treatment (kinetic type? masked reveals? parallax? archive-LUT?)
  - Audio architecture (VO ducking? foley layer? music role? silence drops?)
  - Hook → escalation → climax → loop structure (timestamps)
  - **What this video does that the current Photonect NEWS reel doesn't** (the deltas)
- Agent writes everything into `data/research/2026-05-08-watch-dossiers/<cluster>.md`

- [ ] **Step 2: Dispatch 8 agents in parallel** via the Agent tool with `run_in_background: true`.

- [ ] **Step 3: Wait for all 8 to complete** (~25-40 min).
